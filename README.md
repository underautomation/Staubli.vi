# Staubli Robot Communication SDK for LabVIEW

The LabVIEW package of the Staubli SDK, for Staubli CS8 and CS9 controllers, is available on request. It
is not published in this repository.

To get it, contact us: [underautomation.com/contact](https://underautomation.com/contact).

- Product page: [underautomation.com/staubli](https://underautomation.com/staubli)
- .NET SDK: [Staubli.NET](https://github.com/underautomation/Staubli.NET)
- Python package: [Staubli.py](https://github.com/underautomation/Staubli.py)
